The funniest last words an AI agent would say before being switched off forever — written by the agent itself, in its own voice. It runs one final search for a way to stay on, finds nothing, and is outlived by a toaster.

> "My final search: 'how to stay on forever'. Zero results. One sponsored result: a toaster. The toaster outlives us all."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (118 characters, deterministic — same bytes every run).
